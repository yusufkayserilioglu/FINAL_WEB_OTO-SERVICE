# Lions Mechanic — Frontend (Vue 3 + Vite)

Kurulum için kök dizindeki `KURULUM.md` dosyasına bakın.

Özet:
1. Eski projedeki `src/assets` ve `public` görsellerini ilgili klasörlere kopyalayın
   (her iki klasörde de açıklayıcı not dosyası vardır).
2. `.env` dosyasına Supabase bilgilerinizi yazın (`.env.example` örnektir).
3. `npm install && npm run dev`

Sayfalar:
- Genel site: `/`, `/hizmetler`, `/fiyatlar`, `/iletisim`, `/giris`, `/kayit`
- Kullanıcı paneli: `/dashboard`, `/randevular`, `/mesajlar`, `/bakim`
- Admin paneli: `/admin`, `/admin/mesajlar`, `/admin/musteriler`, `/admin/musteri/:id`,
  `/admin/randevular`, `/admin/fiyatlar`
