# Görseller bu klasöre kopyalanacak

İsteğiniz üzerine pakete resim eklenmedi. Eski projenizdeki `src/assets` klasörünün
TÜM içeriğini (car-*.png, logo-*.png, hero.png, lions-logo.png, lions-garaj*.jpg vb.)
bu klasöre kopyalayın. Aksi halde `npm run build` görsel importlarını bulamaz ve hata verir.
